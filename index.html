Make agent authority inspectable.

This repository is both a working notebook and a sequence of small prototypes. Each prototype exists to answer one architectural question, and failed assumptions are preserved rather than edited out of the story.

The agent's world is a materialized projection, not the environment it happens to be running in. Sandbox is how it is contained; checkout is what it was handed.
