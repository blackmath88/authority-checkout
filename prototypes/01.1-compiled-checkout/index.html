Prototype 01.1 · single-artifact dual consumption

One artifact. Two consumers.

Prototype 01 tested legibility. 01.1 tests the stronger claim: source inputs compile into one checkout artifact, and both the human view and the simulated runtime consume that same artifact. If either consumer relies on parallel hidden authority state, the experiment fails.
